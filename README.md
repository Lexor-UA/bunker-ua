# CYBERLIGA UA • Всеукраїнська платформа турнірів 1v1 для EA SPORTS FC 27

Преміальна Full-Stack платформа для проведення українських турнірів 1 на 1 з **EA SPORTS FC 27** із підтримкою єдиної сезонної екосистеми:
- **Місячні Кубки України (10 000 ₴)** — щомісячні турніри з нарахуванням очок Всеукраїнського рейтингу та прямою путівкою чемпіона у Фінал Року.
- **Всеукраїнський Річний Гранд-Фінал (100 000 ₴)** — головний турнір року на 32 найкращих гравці України (12 чемпіонів місяців + ТОП-20 сезонного рейтингу).

## Основні можливості MVP

1. **Універсальна система ігрових режимів та Жеребкування по командам (Драфт клубів)**:
   - Підтримка **Kick-Off / Online Friendlies 1v1** із криптографічно чесним рандомним драфтом клубів із кошиків (`4.5★ Збалансовані клуби + Шахтар / Динамо`, `5★ Гранди` або `Усі 32 топ-клуби Європи та УПЛ`) та опцією `95 OVR`.
   - Підтримка **Ultimate Team (FUT 1v1)**.
   - Інтерактивна **Студія Церемонії Жеребкування** з покроковим та автоматичним live-показом розкриття клубів і груп.
2. **Посів по 4 кошиках рейтингу та Груповий етап**:
   - Автоматичний розподіл гравців на Кошики 1–4 за очками Всеукраїнського рейтингу.
   - Живі таблиці груп (І, В, Н, П, М'ячі, РМ, Очки, тай-брейк за особистими зустрічами та різницею м'ячів) + календар матчів на 3 тури.
3. **Крос-сітка Плей-офф (Single Elimination)**:
   - Автоматична побудова сітки `1/8` → `1/4` → `1/2` → `Гранд-Фінал` + `Матч за 3-тє місце` з розведенням одногрупників у різні половини сітки.
   - Підтримка серії пенальті та автоматичне просування переможців по сітці.
4. **Кімната матчу 1v1, Скріншоти та Суддівський Арбітраж**:
   - Швидке копіювання `EA ID` та `Telegram` суперника.
   - Внесення рахунку гравцями + завантаження скріншоту підсумкового екрану EA FC 27.
   - Подача протесту («Викликати Суддю») та черга **Арбітражу** в Студії Адміна.
5. **Вбудований контроль EA Community Tournament Guidelines ($10,000 USD / рік)**:
   - Автоматичний трекер сумарного річного призового фонду в грн та USD (ліміт до `$10,000/рік` без комерційної ліцензії) та обмеження стартового внеску `≤ $20`.
   - Офіційний юридичний дисклеймер та кастомні геральдичні щити клубів без порушення торгових марок EA / UEFA.

## Запуск проєкту

Вимоги: **Node.js 22.5+ / 24+** (використовується вбудована реляційна база даних `node:sqlite` у `data/cyberliga.db` без зовнішніх серверів).

```bash
npm install
npm run dev
```

Відкрийте `http://localhost:3000` у браузері.
